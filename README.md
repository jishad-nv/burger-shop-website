# ZaidBites — Burgers, Pizza, Rolls & Drinks

Interactive food ordering web application and admin management dashboard for **ZaidBites**, built with React, TypeScript, Tailwind CSS, Motion, and Firebase (Firestore & Authentication).

## Features

- **Interactive 3-Slide Hero Showcase**: Smooth circular motion transitions between Signature Burger, Loaded Roll, and Wood-Fired Pizza.
- **Click-to-Expand Category Menu**: Browse **Burgers**, **Pizza**, **Rolls & Wraps**, and **Drinks** directly on the homepage with instant 6-product expansion per category.
- **Cart & Checkout Flow**: Customize sizes and add-ons, apply promo codes (`ZAID50`), and place orders with Cash on Delivery or Online Payment.
- **Admin Dashboard (`/admin`)**: Real-time order management, menu & inventory control, and category/promo management backed by Firebase Firestore.

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
